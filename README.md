# Multi-Model AI Chatbot

A simple and interactive AI chatbot built with **Python** and **Streamlit**. The application allows users to interact with multiple Large Language Models (LLMs) from a single interface.

## Models Supported

- OpenAI
- Google Gemini
- Ollama

The application also includes a **Compare All** option to view responses from all three models and compare their response times.

## Features

- Interactive Streamlit chatbot interface
- OpenAI integration
- Google Gemini integration
- Ollama local model integration
- Model selection and routing
- Compare All mode
- Temperature control
- Maximum output token control
- Custom system prompt
- Chat history during the current session
- Response-time display
- Clear Chat option

## Technologies Used

- Python
- Streamlit
- OpenAI API
- Google Gemini
- Ollama

## Installation

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd Multi-Model-AI-Chatbot
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

## API Configuration

The application reads the following API keys from environment variables:

```text
OPENAI_API_KEY
GEMINI_API_KEY
```

Set these variables in your local environment before running the application.

**Never upload or expose API keys in the GitHub repository.**

## Ollama Setup

Install Ollama on your computer and download the model used by this project:

```bash
ollama pull gemma3
```

Make sure Ollama is running before starting the Streamlit application.

The model can be changed in `app.py`:

```python
OLLAMA_MODEL = "gemma3"
```

## Run the Application

```bash
streamlit run app.py
```

The application will open in your browser.

## How to Use

1. Start the application.
2. Select a provider from the sidebar.
3. Enter a question in the chat input.
4. Adjust temperature or maximum output tokens if required.
5. Customize the system prompt if needed.
6. View the generated response.
7. Select **Compare All** to compare OpenAI, Gemini, and Ollama.

## Model Routing

```text
User Prompt
    |
    v
Streamlit Chat Interface
    |
    v
Provider Selection
    |
    +--> OpenAI -----> OpenAI Model
    |
    +--> Gemini -----> Google Gemini Model
    |
    +--> Ollama -----> Local Ollama Model
    |
    v
Generated Response
```

## Model Comparison

When **Compare All** is selected, the same prompt is sent to OpenAI, Google Gemini, and Ollama. The application displays each response together with its response time.

## Configuration Options

### Temperature

Controls the level of variation in model responses.

### Maximum Output Tokens

Controls the maximum amount of output generated by the model.

### System Prompt

Defines the general behavior or role of the AI assistant.

Example:

```text
You are a helpful AI assistant.
```

## Chat History

The application uses Streamlit session state to maintain messages during the current application session.

The **Clear Chat** button removes the current chat history.

## Important Notes

- OpenAI and Gemini require valid API credentials.
- Ollama runs locally and does not require a cloud API key for this setup.
- Ollama must be installed and running locally.
- The selected Ollama model must be available on the local system.
- Never commit API keys or other sensitive credentials to GitHub.
